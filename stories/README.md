# Stories

This directory contains the engineering work items used to develop this repository.

Each Story should have its own directory:

```text
stories/
└── 0001-short-title/
    ├── story.md
    ├── repository-analysis.md
    ├── implementation-plan.md
    ├── implementation-report.md
    ├── code-review.md
    └── engineering-report.md
```

Only `story.md` is created initially.

The remaining artifacts are produced progressively by the `engineering-story` workflow.
