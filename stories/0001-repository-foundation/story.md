## Goal

Establish the foundational structure of the Engineering Skills repository.

The repository should become the reference implementation for reusable AI engineering workflows.

---

## Context

Engineering Skills is intended to become a reusable library of engineering workflows.

Before implementing additional skills, the repository requires a stable structure and documentation.

---

## Problem

The repository has been initialized but still lacks a complete project foundation.

Without a consistent structure, future skills and documentation will become difficult to maintain.

---

## Scope

- README.md
- CONVENTIONS.md
- ROADMAP.md
- CHANGELOG.md
- stories/
- story-template.md

## Out of Scope

- New engineering skills
- OpenCode integration
- Multi-agent workflows
- Developer OS integration
