# Roadmap

This roadmap defines the long-term evolution of the Engineering Skills project.

The objective is to progressively build a reusable engineering workflow framework for AI-assisted software engineering.

---

# Vision

Engineering Skills provides reusable engineering workflows that can be executed by AI assistants.

Skills coordinate engineering work while preserving human ownership of important decisions.

The repository should remain:

* modular;
* reusable;
* tool-independent;
* versioned;
* well documented.

---

## Repository

---

# Version 0.2 — Shared Components

Introduce reusable components shared by all skills.

Examples:

* shared prompts
* shared templates
* reusable references
* common validation rules

Reduce duplication between skills.

---

# Version 0.3 — Additional Skills

Introduce new engineering workflows.

Planned candidates:

* bug-fix
* documentation
* adr
* architecture-review
* security-review

Each skill should solve one engineering problem.

---

# Version 0.4 — Multi-Agent Workflows

Improve collaboration between AI tools.

Examples:

* Repository Analyst
* Implementation Engineer
* Reviewer

Support orchestration across multiple specialized agents.

---

# Version 0.5 — Workflow Automation

Improve orchestration.

Possible features:

* reusable workflow definitions;
* automatic stage transitions;
* artifact chaining;
* workflow validation.

Human approval remains mandatory.

---

# Version 1.0

Stable public release.

Goals:

* stable repository structure;
* stable workflow model;
* reusable engineering artifacts;
* complete documentation;
* production-ready Engineering Story workflow.

---

# Long-Term Vision

Engineering Skills should become a reusable engineering workflow library.

Future integration targets include:

* Developer OS
* Trading OS
* Engineering Playground

The repository should remain independent while providing engineering workflows that can be reused across projects.
